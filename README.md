# SubTrack — Сервіс управління підписками та спільними витратами

SubTrack — це кросплатформений застосунок для централізованого обліку цифрових підписок, контролю рекурентних витрат та автоматизації сповіщень про майбутні платежі. Сервіс дозволяє розділяти витрати (Split Bills) між користувачами для спільно використовуваних акаунтів та надає аналітику витрат за категоріями й валютами.

Проєкт розробляється впродовж навчального семестру командою студентів спеціальності «Комп’ютерна інженерія».

## Структура проекту
* `docs/` — проєктна документація (SRS, UML-діаграми, ERD, специфікація API).
* `src/` — вихідний код програмного продукту.
